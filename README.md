# Summary
Bootstrap is library for css made by twitter. It's used for adaptive and fast creation of sites for every type of screens. There are 12 column to align items and ready elements like 
navbar, button etc. Works alongside with media queries and don't replace it. In conclusion, this library can be used to do typical work like creating navbars, buttons, cards etc. but for 
specific cases better use custom css.
